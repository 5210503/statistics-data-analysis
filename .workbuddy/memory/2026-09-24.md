### 做法（可复用）

- **不套 concept-material-generator 模板**：该 skill 的 description 明确限定「AI 领域概念」，Python 语法不适用；
  讲义体例改对齐 `notes/第01讲-描述性统计.md`（为什么学 / 核心概念 / 快速上手 / 小结 / 思考题 五节）。
- **5 个子 agent 并行，一人一讲（脚本 + 讲义）**，在 prompt 里下发同一份硬规范：
  仅标准库、禁 input 阻塞、禁随机性、统一 `demo_xxx()` + `main()` 结构、脚本 100~180 行、讲义 70~120 行、
  末尾附「动手改一改」挑战、只允许写自己那两个文件（避免并行写冲突，索引由主 agent 统一维护）。
- **主 agent 必须自己复跑验收**：5 个子 agent 都自报 exit=0，主 agent 仍逐个复跑确认，
  并用 `PYTHONIOENCODING=gbk` 模拟 Windows 中文控制台再跑一遍。

### 关键约束（以后写 Python 教学脚本照此办理）

- **print 里禁 emoji 与非 GBK 字符**：Windows 中文控制台是 cp936，脚本打印 `✅ ❌ ⚠️ → ★` 之类会
  `UnicodeEncodeError` 直接崩。分隔线一律用 ASCII（`====`/`----`/`>>`）；中文、`（）`、`——`、`·` 安全。
  验收方式：`PYTHONIOENCODING=gbk python x.py`，或扫描文件里是否有 GBK 编不出的字符。
- 脚本文件写 UTF-8 + 首行 `# -*- coding: utf-8 -*-`；VSCode 里直接 `python scripts/03_变量.py` 即可跑。
