# 第 06 讲 · 函数

## 一、为什么学函数？

你已经会用 Python 算均值/中位数/标准差（见 `raw/statistics/statistics-exercise-01.py`），
但那段代码把"读数据、打印、验证"全堆在 `main()` 里。当逻辑变多，复制粘贴会让你改一处要改三处、还容易改错。

**函数**解决三件事：

| 好处 | 说明 |
|------|------|
| 封装复用 | 一段逻辑只写一次，到处调用，改一处全局生效 |
| 命名即文档 | 函数名 `describe` 比一段 `print` 更直白地说明"这是什么" |
| 便于单独测试 | 每个函数可独立跑、独立验证，不依赖整段流程 |

> 💡 本讲配套脚本 `scripts/python-basics/07_函数.py` 把"同一段计算写三遍"和"写成函数"对照跑了一遍，结论：函数写法逻辑只写一次。

## 二、核心概念

### 1. 函数的定义与返回值

| 写法 | 含义 |
|------|------|
| `def f(x):` | 用 `def` 定义函数，`x` 是参数 |
| `return 值` | 返回结果；**没有 `return`，函数返回 `None`** |
| `return a, b` | 返回多个值，其实是返回一个**元组** `(a, b)`，可用 `lo, hi = f()` 解包 |

### 2. 参数种类

| 类型 | 示例 | 说明 |
|------|------|------|
| 位置参数 | `describe(vals)` | 按顺序传 |
| 关键字参数 | `describe(values=vals, digits=1)` | 按名字传，顺序随意 |
| 默认参数 | `def f(digits=2)` | 不传就用默认值 |
| `*args` | `def f(*args)` | 接收任意个位置参数，组装成元组 |
| `**kwargs` | `def f(**kwargs)` | 接收任意个关键字参数，组装成字典 |

> ⚠️ **重点坑：默认值不要用可变对象**（如 `[]`）。见第三节。
> 参数顺序口诀：**位置 → 默认 → `*args` → `**kwargs`**。

### 3. 作用域、文档字符串、纯函数

- **作用域**：函数内定义的变量是局部变量，函数外看不到。查找顺序 LEGB：Local → Enclosing → Global → Built-in。
- **`global`** 能改全局变量，但尽量别用——会让函数产生隐蔽副作用，难调试。
- **文档字符串（docstring）**：函数第一行用三引号写的"说明书"，可用 `help(f)` 或 `f.__doc__` 查看（`raw/statistics/statistics-exercise-01.py` 的 `load_scores` 就是这样写的）。
- **纯函数 vs 有副作用**：纯函数只 `return`、不改外界；有副作用的函数内部直接 `print`。做数据分析尽量写纯函数，输出交给调用方。

## 三、Python 快速上手

```python
# 没有 return 的函数，其实返回 None
def greet(name):
    print("你好，" + name)
print(type(greet("小明")))          # <class 'NoneType'>

# 返回多个值，其实返回元组
def min_max(values):
    return min(values), max(values)
print(type(min_max([3, 1, 5])))     # <class 'tuple'>
lo, hi = min_max([3, 1, 5])         # 解包
```

**【重点坑】可变默认参数污染**（已实际运行验证）：

```python
def add_item_bad(item, box=[]):   # 危险：默认列表只创建一次
    box.append(item)
    return box
print(add_item_bad("苹果"))        # ['苹果']
print(add_item_bad("香蕉"))        # ['苹果', '香蕉']  ← 第一次的结果也被改了！

def add_item_ok(item, box=None):  # 正确：None 占位，每次新建
    if box is None:
        box = []
    box.append(item)
    return box
print(add_item_ok("苹果"))         # ['苹果']
print(add_item_ok("香蕉"))         # ['香蕉']  ← 各自独立
```

`*args` / `**kwargs`：

```python
def my_sum(*args):
    return sum(args)
print(my_sum(1, 2, 3, 4, 5))       # 15

def show_config(**kwargs):
    for k, v in kwargs.items():
        print(k, "=", v)
show_config(encoding="utf-8", version=3)
# encoding = utf-8
# version = 3
```

lambda 与类型注解：

```python
scores = [72, 85, 90, 60, 78, 92, 88, 76]
print(sorted(scores, key=lambda x: -x))   # 降序：[92, 90, 88, ...]

def mean_hint(values: list[float]) -> float:   # 注解只给人/工具看
    return sum(values) / len(values)
print(mean_hint([1, 2, 3]))   # 2.0，传错类型也不报错（运行时【不】强制检查）
```

## 四、本讲小结

1. 函数 = 封装复用 + 命名即文档 + 便于单独测试
2. 默认值别用可变对象；参数顺序 位置 → 默认 → `*args` → `**kwargs`
3. 尽量写纯函数（只 `return`），输出交给调用方；文档字符串是函数自带说明书
