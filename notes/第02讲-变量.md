# 第02讲 · 变量

## 一、为什么要学变量？

上一讲你已经用 Python 算过均值、中位数、标准差，但有没有想过：
每次写 `mean = stats.mean(scores)` 时，等号到底在"做"什么？
为什么 `1` 和 `1.0` 在 Python 里是两种不同类型？
为什么给列表 `append` 一下，原来的"名字"还能看到新内容，而字符串拼接却要重新赋值？

这一讲我们补上这块地基——**变量（Variable）**。地基稳了，后面的运算符、流程控制、函数才盖得动。

## 二、核心概念

### 1. 变量是"标签"不是"盒子"

`=` 不是"把值塞进变量"，而是**把右边的对象贴上左边的名字**这个标签。
数据和变量是分开的：数据是可以独立存在的对象，变量只是贴在它身上的便利贴。

```python
score = 88          # 给整数对象 88 贴上 score 标签
another = score     # another 和 score 指向同一个对象
```

> 比喻：变量是贴在对象上的标签，不是盒子本身。重绑定 = 把标签撕下来贴到别的对象上，原对象并不移动。

### 2. 命名规则

| 规则 | 说明 | 例子 |
|------|------|------|
| 合法字符 | 字母、数字、下划线，且不能以数字开头 | `score`、`score_1` 合法 / `1score` 非法 |
| 区分大小写 | `MEAN` 和 `mean` 是两个变量 | — |
| 不能用保留字 | `if`、`for`、`class` 等是关键字 | `class` 非法 |
| PEP 8 惯例 | 小写 + 下划线 snake_case | `student_count` 推荐 |

可用 `keyword.kwlist` 查看全部保留字；判断名字是否合法：
`name.isidentifier() and not keyword.iskeyword(name)`。

### 3. 动态类型：变量无类型，对象有类型

Python 的变量不需要声明类型，换绑对象时类型随之改变：

```python
x = 5          # type(x) -> <class 'int'>
x = "hello"    # type(x) -> <class 'str'>
```

判断类型用 `type()`（看是什么类）或 `isinstance()`（看是不是某类的实例，更适合做判断）。

### 4. 基本类型一览

| 类型 | 字面量例子 | 说明 |
|------|-----------|------|
| int | `10` | 整数 |
| float | `3.14` | 浮点数 |
| bool | `True` / `False` | 布尔值，是 int 的子类 |
| str | `"数据"` | 字符串，用引号包裹 |
| NoneType | `None` | 表示"没有值" |

### 5. 可变与不可变（用 id() 看穿）

每个对象都有唯一身份 `id()`。重绑定后 id 变了 → 不可变；原地修改后 id 不变 → 可变。

| 操作 | 类型 | id 是否变化 | 结论 |
|------|------|------------|------|
| `n = 100; n = 200` | int | 变 | 不可变（重新绑定） |
| `s = "abc"; s = s + "d"` | str | 变 | 不可变 |
| `lst.append(4)` | list | 不变 | 可变（原地修改） |

### 6. 类型转换的坑

| 写法 | 结果 | 注意 |
|------|------|------|
| `int("42")` | `42` | 字符串整数可转 |
| `int("3.5")` | 报错 ValueError | 带小数点的字符串无法解析 |
| `int(3.99)` | `3` | **截断**不是四舍五入 |
| `float("3.5")` | `3.5` | 正常 |
| `bool("")` | `False` | 空字符串为假 |
| `bool("0")` | `True` | 非空字符串一律为真 |
| `bool(0)` / `bool([])` | `False` | 0 和空容器为假 |

> 一句提醒：`input()` 永远返回 str（本讲不调用它），需要时记得用 `int(input())` 等自行转换。

## 三、Python 快速上手

配套脚本 `scripts/python-basics/03_变量.py` 把上面每一条都跑出了真实结果，下面摘录几段：

```python
# 多重赋值与解包
a = b = 1              # a = 1, b = 1
x, y = 1, 2           # x = 1, y = 2
x, y = y, x           # 交换：x = 2, y = 1（无需临时变量）

# 落到统计场景：给中间结果起名字
scores = [72, 85, 90, 60, 78, 92, 88, 76]
mean = sum(scores) / len(scores)        # 80.125
squared_diff = [(s - mean) ** 2 for s in scores]
std_dev = (sum(squared_diff) / len(scores)) ** 0.5
```

把中间量命名为 `mean`、`squared_diff`、`std_dev`，公式读起来就像数学书——这就是"给中间结果起名字"的价值。

## 四、本讲小结

1. 变量是贴到对象上的标签，`=` 是绑定；重绑定只是换标签，数据不挪窝。
2. 变量无类型、对象有类型；int / str 不可变，list 可变（用 `id()` 一看便知）。
3. 类型转换要当心：`int()` 截断而非四舍五入，`int("3.5")` 会直接报错。
