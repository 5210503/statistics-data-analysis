# 第05讲 · 流程控制

## 一、为什么学流程控制？

第 01 讲你用 `statistics` 库算出了均值、中位数、标准差，那些代码是“一条条顺序执行”的。
但真实的数据分析里，你经常需要**根据条件做选择**（分数及格吗？）、**反复做同一件事**（把 1000 个数加起来）、
**跳过或中止循环**（遇到异常值怎么办）。

这些“让程序决定下一步去哪”的能力，就叫**流程控制**（Control Flow）。它包含三大件：

- **分支**：`if / elif / else` —— 不同情况走不同代码
- **循环**：`for` / `while` —— 把一件事重复做 N 遍
- **跳转**：`break` / `continue` —— 在循环里提前退出或跳过

> 例子：想从全班成绩里挑出不及格的人，不用手写 50 次判断，一个 `for` + `if` 就搞定。

## 二、核心概念

### 1. 缩进即语法（Python 最特别的一点）

C/Java 用 `{}` 划代码块，Python **用缩进**（推荐 4 个空格）。同一代码块缩进必须一致，否则直接报错。

| 对比 | 写法 |
|------|------|
| 错（混用空格和制表符、或缩进不一致） | `IndentationError` |
| 对（同一块统一 4 空格） | 见下方代码 |

### 2. 分支：if / elif / else

从上往下匹配，**命中第一个就跳出**，后面的 `elif` 不再判断。

### 3. 真值判断（哪些值被当成“假”）

`if x:` 看的是 `bool(x)`。下面这些值都等价于 `False`：

| 值 | bool() 结果 |
|----|-------------|
| `0` / `0.0` | `False` |
| `""`（空串） | `False` |
| `[]` `{}` `()`（空容器） | `False` |
| `None` | `False` |
| `False` | `False` |

> 实用建议：判断列表非空，写 `if items:` 而不是 `if len(items) > 0:`。

### 4. 循环：for / while

| 结构 | 用途 | 注意点 |
|------|------|--------|
| `for x in 序列` | 遍历已知序列 | 配合 `range()` 生成数字序列 |
| `while 条件` | 条件满足就重复 | **必须有终止条件**，否则死循环（按 Ctrl+C 中断） |

`range(start, stop, step)` 的 **`stop` 取不到**：`range(5)` 是 `0,1,2,3,4`，不含 5。

### 5. 跳转与辅助工具

| 工具 | 作用 |
|------|------|
| `break` | 立刻结束**整个**循环 |
| `continue` | 跳过本次剩余部分，进入下一轮 |
| `enumerate()` | 遍历时同时拿到下标和值 |
| `zip()` | 并行遍历多个序列（以短的为准） |

> `break` / `continue` 只影响**最内层**那一层循环。

## 三、Python 快速上手

```python
# 写法 → 输出结果
if 5 > 3:            # 命中即跳出
    print("命中")    # 命中

for v in [0, "", [], None]:
    print(bool(v))   # False False False False

for i in range(5):
    print(i)         # 0 1 2 3 4（不含 5）

for i, f in enumerate(["苹果","香蕉"]):
    print(i, f)      # 0 苹果 / 1 香蕉

for n, s in zip(["小明","小红","小刚"], [85, 92]):
    print(n, s)      # 小明 85 / 小红 92（小刚被忽略）
```

统计场景：用循环手算均值与标准差（呼应第 01 讲）。完整可运行代码见 `scripts/python-basics/06_流程控制.py`，
其中手算结果：均值 `80.125`、总体标准差 `10.105`（除以 n）；
而第 01 讲 `statistics.stdev` 是样本标准差（除以 n-1），所以两者数值略有不同——这是分母差异，不是算错。

## 四、本讲小结

1. 缩进即语法：4 个空格，同一块必须一致，没有大括号 `{}`。
2. `for` 遍历序列、`while` 看条件；`range` 的 `stop` 取不到；`break/continue` 只影响最内层循环。
3. `enumerate` 拿下标、`zip` 并行遍历；手算统计量能帮你看懂循环到底在干什么。
