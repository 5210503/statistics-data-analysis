# 第03讲 · 运算符

## 一、为什么学运算符？

上一讲你用 `statistics.mean()` 算过均值，但那一行代码里其实藏着一堆运算符：
`+`、`-`、`*`、`/`、`//`、`%`、`**`、`==`、`and`、`in`…… 它们是 Python 的
"零件"，几乎所有数据操作都由它们组合而成。

本讲把运算符一次性讲清，重点不是"符号长啥样"，而是**哪些地方反直觉、容易踩坑**：
为什么 `-7 // 2 == -4`？为什么 `0.1 + 0.2 != 0.3`？`==` 和 `is` 到底差在哪？

## 二、核心运算符

### 1. 算术运算符

| 运算符 | 含义 | 易错点 |
|--------|------|--------|
| `/`  | 真除法 | **永远返回 float**，哪怕能整除（5/2=2.5） |
| `//` | 整除（向下取整） | 负数也向下：`-7 // 2 = -4`（不是 -3） |
| `%`  | 取余 | 余数符号**跟除数走**：`-7 % 2 = 1` |
| `**` | 幂 | 整数底数返回 int；`math.pow` 永远返回 float |

```python
5 / 2   = 2.5          # / 永远 float
5 // 2  = 2            # 向下取整
-7 // 2 = -4           # 负数：floor(-3.5) = -4
-7 % 2  = 1            # -7 = 2*(-4) + 1
2 ** 10 = 1024         # ** 是整数幂
math.pow(2, 10) = 1024.0   # 永远 float
```

### 2. 比较运算符：`== != < <= > >=`

结果是 `bool`。关键区别在 `==`（比"值"）和 `is`（比"是不是同一个对象"）；判断空值一律写 `x is None`，不要写 `x == None`：

| 类型 | `a == b` | `a is b` |
|------|----------|----------|
| int  | `1000 == int('1000')` → True | → **False**（两个对象） |
| str  | `'data' == ''.join(['d','a','t','a'])` → True | → False |
| list | `[1,2,3] == [1,2,3]` → True | → False |

### 3. 逻辑运算符：`and or not`

- **短路求值**：`False and 右侧` 右边不执行；`True or 右侧` 右边不执行（可用带 print 的函数验证）。
- `and` / `or` 返回的是**操作数本身**，不一定是 True/False：`0 and 5 → 0`，`3 and 5 → 5`。

### 4. 赋值运算符 `+= -= *= /= //= %= **=`

对不可变对象（int/str）是"重新绑定"；对可变对象（list）`+=` 是**原地修改**：

```python
lst = [1, 2, 3]; ref = lst
lst += [4]          # 原地修改
ref                 # [1, 2, 3, 4]（ref 跟着变）
```

### 5. 成员运算符 `in` / `not in`

用于 str、list、dict 的**键**：`'a' in 'cat' → True`，`'math' in d → True`。

### 6. 位运算符（点到为止）

`& | ^ ~ << >>`：处理二进制位。`1 << 3 = 8`（左移 = 乘 2³），`16 >> 2 = 4`（右移 = 整除 2²）。
日常数据分析很少手写，认识即可。

### 7. 运算符优先级

别背整张大表，记住**记忆主线**：`算术 > 比较 > 逻辑 > 赋值`。

| 反直觉例子 | 结果 | 真相 |
|------------|------|------|
| `2 + 3 * 4` | 14 | 乘法先于加法 |
| `True or False and False` | True | `and` 先于 `or` 算 |

> **不确定优先级，一律加括号**：`(2 + 3) * 4 = 20`。

### 8. 浮点精度陷阱

```python
0.1 + 0.2 == 0.3          # False！二进制存不下
round(0.1 + 0.2, 1)       # 0.3（保留小数）
math.isclose(0.1+0.2, 0.3) # True（推荐的比较方式）
```

## 四、本讲小结
1. `/` 永远 float；`//` 向下取整（负数同理）；`%` 符号跟除数走；`**` 是整数幂、`math.pow` 永远 float。
2. `==` 比"值"、`is` 比"同一对象"；判断 None 用 `is None`；`and/or` 返回操作数本身且会短路。
3. 浮点别用 `==` 比较，用 `round()` 或 `math.isclose()`；优先级不确定就加括号。
