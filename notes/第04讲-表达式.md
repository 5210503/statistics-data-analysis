# 第04讲 · 表达式

## 一、为什么学表达式？

第 03 讲我们逐个认识了运算符（+、-、*、/、==、and……），但“运算符”只是积木，
“表达式”才是把积木拼起来、**会算出一个值**的东西。

很多人写了一段 `x = a + b * c` 却说不清：到底哪里是表达式、哪里是语句？
为什么 `2 ** 3 ** 2` 等于 512 而不是 64？为什么 `value = user_input or "默认值"` 能当默认值用？
本讲把“表达式”这件事单独拎出来讲，帮你写出更短、更地道、更少 bug 的统计代码。

## 二、核心概念

### 1. 表达式 vs 语句

| 类别 | 有没有值 | 例子 | 说明 |
|------|----------|------|------|
| 表达式 | 一定有值 | `1 + 2`、`len(scores)` | 可以被“求值”并继续参与运算 |
| 语句 | 不一定 | `x = 1`、`print("x")` | 主要用来“做事” |

> 💡 反直觉点：`print("x")` 也是表达式！它有副作用（打印），返回值是 `None`。
> 而 `x = 1` 整体是“赋值语句”，不是表达式——Python 不允许写 `y = (x = 1)`。
> 但 `x = 1 + 2` 里，`1 + 2` 是表达式，先算出 3 再赋给 x。

### 2. 求值顺序：优先级 + 结合性

| 写法 | 结果 | 解释 |
|------|------|------|
| `2 + 3 * 4` | 14 | 先乘后加（优先级） |
| `2 ** 3 ** 2` | 512 | 幂运算**右结合**：`2 ** (3 ** 2) = 2 ** 9` |
| `not a == b` | False | `==` 优先于 `not` |
| `(2 + 3) * 4` | 20 | 括号强制先算，且更清楚 |

> 💡 黄金法则：**拿不准就加括号**。括号不改变机器结果，但能让读代码的人一眼看懂。

### 3. Python 特有的几种表达式

| 表达式 | 写法 | 输出结果 | 用途 |
|--------|------|----------|------|
| 短路（or） | `value = user_input or "默认值"` | 取第一个“真”值 | 给默认值 |
| 短路（and） | `result = x and x.name` | x 为假直接返回 x | 防空出错 |
| 三元 | `a if cond else b` | 条件成立取 a，否则取 b | 一行分支 |
| 海象 | `if (n := len(data)) > 3:` | 边算边绑定 n | 避免重复计算 |
| 解包 | `a, b = b, a` | 交换两个变量 | 无需临时变量 |
| 收集 | `first, *rest = [1,2,3,4]` | `rest = [2,3,4]` | 拆出剩余项 |
| 比较链 | `0 < score <= 100` | 等价于 `0 < score and score <= 100`，但 score 只求值一次 | 区间判断 |

### 4. f-string 里的表达式（做报告最常用）

```python
a, b = 3, 4
x = 1.234567
ratio = 0.375
print(f"a + b = {a + b}")            # a + b = 7
print(f"x 保留两位小数   : {x:.2f}")  # 1.23
print(f"ratio 百分比     : {ratio:.1%}")  # 37.5%
print(f"{a + b = }")                 # a + b = 7（3.8+ 调试写法）
```

> 💡 `:.2f` 固定小数位、`:.1%` 直接变百分比、`{expr = }` 连表达式带结果一起打印，
> 写统计报告时不用再单独起变量名。

## 三、Python 快速上手

```python
# 短路：右侧未被求值的证明
def noisy():
    print("    noisy 被调用了")
    return "响了"
print(True or noisy())     # 打印 True，noisy 没被调用（短路）
print(False and noisy())   # 打印 False，noisy 没被调用（短路）

# 海象：算了还要再用一次
data = [12, 19, 7, 23]
if (n := len(data)) > 3:
    print("列表长度", n, "超过 3")   # 列表长度 4 超过 3

# 比较链只求值一次
score = 85
print(0 < score <= 100)    # True（score 只算了一次）
```

落到统计场景，一个表达式直接算出 z-score 并格式化及格率：

```python
scores = [72, 85, 90, 60, 78, 92, 88, 76]
mean = sum(scores) / len(scores)
std = (sum((s - mean) ** 2 for s in scores) / len(scores)) ** 0.5
z = lambda s: (s - mean) / std
print(f"均值: {mean:.2f}  标准差: {std:.2f}")
print(f"分数 90 的 z-score: {z(90):.2f}")
print(f"及格率: {sum(1 for s in scores if s >= 60) / len(scores):.1%}")
```

## 四、本讲小结

1. 表达式“有值”、语句“做事”；函数调用也返回 `None`，别被副作用骗了
2. 拿不准求值顺序就加括号——括号是写给读代码的人看的
3. 短路 / 三元 / 海象 / 解包 / f-string 表达式，能让统计代码更短更清楚
