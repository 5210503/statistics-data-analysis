# 统计与数据分析 · 学习仓库

> 学习统计与数据分析课程的笔记、代码与练习。
> 从零基础到能独立完成一份数据分析报告。

## 📚 学习路线

| 阶段 | 主题 | 核心内容 | 状态 |
|------|------|----------|------|
| 一 | 描述性统计 | 均值/中位数/方差/标准差、直方图、箱线图 | 🔄 进行中 |
| 二 | 概率基础 | 随机事件、条件概率、常见分布（正态/二项/泊松） | ⬜ 未开始 |
| 三 | 推断统计 | 抽样、置信区间、假设检验（t 检验、卡方检验） | ⬜ 未开始 |
| 四 | 相关与回归 | 相关系数、一元/多元线性回归 | ⬜ 未开始 |
| 五 | 综合实战 | 完整数据分析项目（提出问题→分析→结论） | ⬜ 未开始 |

## 🛠️ 环境说明

- Python 3（练习代码目前只用标准库，后续会用到 pandas / matplotlib / numpy）
- 每个练习脚本都可以直接运行：`python exercises/ex01_描述统计入门.py`（需在 exercises 目录下）

## 🔄 Git 日常三步曲（每次学完新内容提交）

```bash
git add .                                          # 1. 收集修改

git push                                           # 3. 推送到 GitHub
```
